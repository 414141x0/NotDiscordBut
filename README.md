# NotDiscordBut
A native Swift/macOS-iOS(WIP) client for Discord client.
`NotDiscordBut` is a modular Swift package with separate layers for Discord primitives, HTTP transport, gateway handling, authentication, persistence, state, feature composition, and macOS/iOS app target.
> Experimental project. Not affiliated with Discord.

## Requirements
- macOS 14+
- Swift 6.3+
- Xcode or Command Line Tools

## Build and Run
```bash
./script/build_and_run.sh
```

## Status

MacOS app supports messages, reacts, and most of the required functionalities.
